# CrimeLens AI

CrimeLens AI is an AI-assisted crime investigation and digital forensics platform.

## Features
- Case management
- Evidence management and file uploads
- Suspect and witness management
- AI-assisted case analysis
- Secure login
- Investigation reports

## Technologies
- Python
- Flask
- PostgreSQL
- HTML
- CSS
- JavaScript
- AI
